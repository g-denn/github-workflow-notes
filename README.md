# GitHub workflow notes

A small, independent guide to keeping GitHub changes easy to review and safe to merge.

## The basic loop

1. Write down the problem and the result you expect.
2. Make one focused change on a branch.
3. Open a pull request that explains the change and how you checked it.
4. Review the diff and checks before merging.
5. Confirm the result, then close any linked issue.

These notes are for learning and can be adapted to a project's own contribution rules.
